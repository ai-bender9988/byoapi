⚙ Options

On by default. Swaps every Grok system prompt in this app (Image/Video Prompt Assistant, Story generation, scene rewrites, motion prompts — thirteen in total) for its explicit counterpart, editable individually below under "Grok prompts". Remembered across restarts, same as every other setting here — it stays however you left it. Only changes which instructions Grok gets; kie.ai's/xAI's own content moderation on the actual image/video generation calls still applies independently.

API keys

Stored in plain text in kie_key.txt / xai_key.txt (same folder as proxy.py) — the same files you could already edit by hand, just editable from here too. Leave a field blank to keep its current value; a key that's already saved is never shown back here, only whether one is set.

Seed control

Off by default. When on, a "Seed" field appears on the Image and Video tabs — but only for the three kie.ai models that actually accept one (WAN 2.7 Image, WAN 2.7 First/Last Frame to Video, WAN 2.7 Reference to Video; confirmed against kie.ai's own API docs — every other model here has no seed parameter at all). Leave the field blank for a random result each time (the default either way); fill it in to reproduce or nudge a previous result.

Video models

Unchecked models disappear from the model dropdowns (Image tab, Video tab, Story tab's video engine) and are rejected if requested anyway, even from a stale tab.

Grok backend

Every Grok call in this app (Story generation, Prompt Assistant, scene video prompts) normally goes through kie.ai's Grok proxy. If kie.ai starts erroring out, switch to calling xAI's own API directly instead — needs your own xAI API key (see "API keys" above). This is a manual switch, not automatic on error — kie.ai stays the default until you change it here.

Spend cap

Once the All-time spend estimate (top of the page) reaches this amount, new kie.ai image/video jobs are refused — enforced server-side, so it holds even from a stale tab. Set to 0 to disable. This is still an estimate against estimates, not exact kie.ai billing — see the disclaimer above the tabs.

Pricing (kie.ai rate overrides)

Only affects the cost estimates shown in this app, not what kie.ai actually charges — update these if kie.ai's published rates change.

Grok prompts

Every system prompt Grok is given anywhere in this app, in one place, clearly labeled by which part of the app sends it — click one to expand and edit it. These are the same prompts (and the same override file) as the "✎ Edit system prompt" button embedded in the Image/Video Prompt Assistant panels — editing one here or there changes the same thing. Each one also has a separate "NSFW" version below it, used instead of the normal one whenever NSFW mode (see the top of this panel) is on — both start pre-filled with a real built-in prompt, editable and resettable independently.
